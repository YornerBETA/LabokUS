# Kolobok / LabokUS project context

Personal assistant named Колобок. Main repository: Yor​​nerBETA/LabokUS. Current first release: 1.0.0/W/Russian, Windows 10 x64, Python/Tkinter, local SQLite, chat and OpenAI-compatible API. Read README and docs before editing.

Release folders: <version>/<platform>/<installer-language>/. Codes: W, LX, MO, AND, iOS. Do not place Android APK in Windows package. install.bat currently builds an EXE locally with PyInstaller; it is not yet a signed MSI/EXE installer or automatic updater.

Target languages: Python, C#, C++, Java, JavaScript, Node.js, HTML, CSS, SQL, Go; PHP optional. Target hardware is a modest Intel Core i5 laptop with weak graphics: avoid GPU-heavy workloads and Blender dependency.

Never commit API keys, passwords, or user data. Render Free sleeps and has ephemeral filesystem; do not promise 24/7. Monitoring requires explicit opt-in, visible indicator, scoped permissions and emergency stop. Distinguish implemented features from roadmap.
