# Колобок / LabokUS — контекст проекта для Gemini

Разрабатывай Колобка (Kolobok) — персонального AI-ассистента. Репозиторий: https://github.com/YornerBETA/LabokUS. Колобок — имя продукта; GPT, Gemini, Claude, Qwen, Kimi и другие модели — подключаемые провайдеры.

## Версия и каталоги
Текущая версия 1.1.0. Путь Windows-сборки: 1.1.0/W/x64/ru/all/.
W = Windows; x64 = архитектура; ru = русский человеческий язык интерфейса/установщика; all = комплект языков программирования, а не язык интерфейса. Будущие платформы: LX (Linux), MO (macOS), AND (Android), iOS. Архитектура указывается отдельно: x64, x86, arm64 и т. п. Не смешивай APK/AAB с EXE/MSI.
Языковой набор: Python, Java, JavaScript, TypeScript, C, C++, C#, Kotlin, Go, HTML, CSS, SQL, PowerShell, Bash; PHP необязателен. Наличие в списке не означает, что компилятор уже встроен.

## Оборудование
Цель — Windows 10 на слабом ноутбуке Intel Core i5 с интегрированной/слабой видеокартой (раньше Windows 7, затем переустановлена Windows 10). Не требуй Blender, Unity, Unreal, CUDA или мощный GPU. Делай лёгкий UI, CPU-friendly геометрию и облачную обработку тяжёлых задач.

## Архитектура
Windows Desktop, браузерный UI без десктопного маскота, Cloud API, локальный агент Windows с явным разрешением, расширения с манифестами/разрешениями/проверкой и песочницей. Мониторинг ПК должен иметь видимый индикатор, ограниченные права, журнал и аварийную остановку. Никакого скрытого наблюдения. Не запускай недоверенные плагины автоматически.

## API и безопасность
Пользователь сам задаёт API-ключи/OAuth. Используй OpenAI-compatible API там, где это поддерживается, и отдельные адаптеры Gemini/Anthropic. Не помещай секреты в GitHub, ZIP или frontend JavaScript. Учитывай лимиты бесплатных тарифов; не обещай бесконечные запросы/вычисления.

## Telegram
Используй официальный Telegram Bot API. Компьютеру с Колобком не требуется открывать Telegram Web или Telegram Desktop. Пользователь создаёт бота через @BotFather, задаёт токен и один раз начинает приватный диалог с ботом. Ограничивай allowed_user_ids. Пользователю всё равно нужен Telegram-клиент на устройстве, чтобы читать сообщения. Не публикуй токены.

## Голос
Целевые режимы: Voice→Voice, Text→Text, Voice→Text, Text→Voice. В будущем: потоковый микрофон, STT/TTS, wake phrase «Привет, Колобок», barge-in и выбор устройств. Текущий прототип ограничен локальным Windows TTS и распознаванием выбранного аудиофайла через API. Не называй это полноценным постоянно слушающим агентом, пока нет потокового микрофона и двустороннего диалога. Микрофон — только с явным разрешением, индикатором и остановкой.

## Обновления
У Колобка и AI API отдельные версии. Уведомляй раздельно. Галочка «Больше не спрашивать» убирает стартовое окно, но оставляет постоянное уведомление внутри приложения. Никакой автоматической установки. Универсальный установщик показывает GitHub Releases, фильтрует ОС/архитектуру/язык/языковой набор и устанавливает только после нажатия. Проверяй SHA-256 при наличии checksum.

## Память, музыка и 3D
Узлы графа знаний должны сохранять ID, источник, временные метки, теги, важность, качество, требования к контексту, связи и оценки. При импорте сохраняй происхождение данных. Не сохраняй пароли/токены. Не раскрывай скрытые цепочки рассуждений; сохраняй краткие выводы, доказательства, действия и результаты. Текущая 3D-лаборатория — лёгкий wireframe-прототип, не замена Blender. Музыкальный модуль создаёт оригинальные сигналы; не копируй защищённые записи и саундтреки.

## Платформы
GitHub — основной код/релизы. Render Free может засыпать, а локальные файлы эфемерны; для постоянной облачной памяти нужна отдельная БД. Vercel — дополнительный frontend, для GitHub-привязки нужен GitHub Login Connection. GitLab — необязательный приватный репозиторий знаний. Replit — отдельная среда разработки, не изменяй чужие приложения. GitBook необязателен. Cloudflare необязателен; не создавай платные ресурсы без согласования. Доступ ChatGPT-коннектора не означает автоматический доступ Колобка — нужны его собственные ключи.

## Правила
Сначала читай фактический код. Различай готовое, прототип, план и непроверенное. Проверяй синтаксис и тесты, сообщай только реальные результаты. Сохраняй совместимость Windows 10. Для БД используй миграции и резервные копии. Применяй HTTPS, аутентификацию, лимиты, тайм-ауты, повторы, логи и валидацию. Не коммить .env, токены, базы и экспорты переписок. Не создавай бесконечные циклы агентов: бюджеты, checkpoints, cancel и лимиты обязательны. Не заявляй об успешном deploy без подтверждения хостинга.

## Текущее состояние

Код удалённого MCP-сервера добавлен в cloud backend, но плагин заработает только после успешного последнего deploy на Render.
