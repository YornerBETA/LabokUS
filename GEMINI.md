# Контекст проекта Колобок / LabokUS

Колобок — персональный ассистент. Репозиторий Yor​​nerBETA/LabokUS. Первая версия: 1.0.0/W/Russian, Windows 10 x64, Python/Tkinter, SQLite, чат и OpenAI-совместимый API.

Структура выпусков: <version>/<platform>/<installer-language>/. Коды: W, LX, MO, AND, iOS. Не смешивать APK с Windows-файлами. install.bat пока локально собирает EXE через PyInstaller, но ещё не является полноценным подписанным установщиком/автообновлятором.

Целевые языки: Python, C#, C++, Java, JavaScript, Node.js, HTML, CSS, SQL, Go; PHP необязателен. Компьютер слабый, Intel Core i5 и слабая графика — не требовать Blender/GPU. Не коммитить секреты. Render Free засыпает и теряет локальные файлы при перезапуске. Мониторинг ПК — только с разрешением, индикатором и остановкой.
