# Universal installer — Windows / ru

The installer lists compatible published GitHub Releases and filters by platform, architecture, human language and programming-language pack. The user selects a release and explicitly clicks Install. It never installs updates automatically.

Expected asset pattern: `LabokUS-<version>-W-<arch>-ru-all.zip`. A matching `.sha256` asset is checked when present. See the separate installer ZIP for the current Python/Tkinter bootstrapper.
