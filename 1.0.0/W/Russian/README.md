# Колобок 1.0.0 — Windows / Russian

Первая локальная версия LabokUS. Требуется Windows 10 x64 и Python 3.10–3.12.
- run.bat — запуск приложения.
- install.bat — создание venv и сборка EXE через PyInstaller.
- manifest.json — версия, ОС, архитектура и язык установщика.

Важно: install.bat пока собирает EXE на компьютере пользователя; это не готовый подписанный MSI/EXE-инсталлятор. Пользовательские данные хранятся в %APPDATA%\\Kolobok. Не помещать API-ключи в репозиторий.
