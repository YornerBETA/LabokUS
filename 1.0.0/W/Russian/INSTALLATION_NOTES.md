# Установка и диагностика

1. Распакуй ZIP в обычную папку, например C:\\Kolobok.
2. Запусти diagnostics.bat, если нужно проверить ноутбук. Отчёт сохранится на рабочем столе; проверь его на личные сведения перед отправкой.
3. Установи Python 3.10–3.12 x64, если его нет.
4. Запусти install.bat: он создаст виртуальное окружение, установит PyInstaller и соберёт приложение.
5. Запускай run.bat.

Если сборка падает, сохрани последние строки ошибки. Не отключай антивирус и не запускай установщик от администратора без необходимости.
