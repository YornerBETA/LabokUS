# Колобок 1.1.0 — Windows x64 / ru / all

`ru` — русский человеческий язык интерфейса и установщика. `all` — набор поддерживаемых языков программирования.

Поддерживаемый набор: Python, Java, JavaScript, TypeScript, C, C++, C#, Kotlin, Go, HTML, CSS, SQL, PowerShell и Bash; PHP необязателен. Это целевой набор интеграций, не утверждение, что все компиляторы поставляются в комплекте.

Windows 10 x64. Запуск исходников: установить Python 3.10+ x64, запустить `install.bat`, затем `run.bat`. Данные пользователя — в `%APPDATA%\Kolobok`.

Обновления только вручную. Приложение показывает доступные обновления Колобка и AI API отдельно, не устанавливает их без нажатия пользователя.
