# LabokUS / Колобок

Персональный ассистент Колобок. Главный репозиторий исходников, версий и выпусков.

## Первая Windows-версия

Путь: `1.0.0/W/Russian/`

- `app/main.py` — Windows desktop-прототип на Python/Tkinter.
- `run.bat` — запуск приложения.
- `install.bat` — создание виртуального окружения и сборка EXE через PyInstaller.
- `manifest.json` — метаданные версии, платформы, языка и минимальной ОС.
- `diagnostics.bat` — локальная диагностика Windows и оборудования.

Это ранний прототип: полноценный установщик-загрузчик, который сам получает каталог релизов, выбирает версию/язык и скачивает проверенный пакет с GitHub, ещё предстоит реализовать. Текущий `install.bat` собирает приложение на компьютере разработчика/пользователя с Python.

## Каталог версий

`<version>/<platform>/<installer-language>/`

Коды платформ: `W` = Windows, `LX` = Linux, `MO` = macOS, `AND` = Android (APK/AAB), `iOS` = iOS. Платформенные сборки не смешиваются: Windows не предлагает APK, Android не предлагает EXE/MSI. Язык установщика — отдельная папка, например `Russian` или `English`.

## Безопасность и ограничения

- API-ключи, пароли и пользовательские базы не коммитятся.
- Пользовательские данные Windows хранятся в профиле пользователя.
- Для будущих обновлений обязательны HTTPS, SHA-256/подпись и откат.
- Бесплатный Render может засыпать, а его локальная файловая система эфемерна.
- Не считать функции из ROADMAP уже реализованными.
