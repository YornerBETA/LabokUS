# LabokUS / Колобок

Главный репозиторий исходников, версий и выпусков персонального ассистента Колобок.

## Текущий выпуск

**1.1.0 / Windows x64 / ru / all**

Путь: `1.1.0/W/x64/ru/all/`

- `W` — Windows.
- `x64` — архитектура.
- `ru` — человеческий язык интерфейса и установщика.
- `all` — набор языков программирования проекта, а не человеческий язык.

Набор `all`: Python, Java, JavaScript, TypeScript, C, C++, C#, Kotlin, Go, HTML, CSS, SQL, PowerShell, Bash; PHP необязателен. Перечень не означает, что компиляторы всех языков включены в установщик.

## Версии

`<version>/<platform>/<architecture>/<human-language>/<programming-language-pack>/`

Примеры: `1.1.0/W/x64/ru/all/`, `1.1.0/W/x86/ru/all/`, `1.1.0/LX/x64/ru/all/`, `1.1.0/MO/arm64/ru/all/`, `1.1.0/AND/arm64/ru/all/`, `1.1.0/iOS/arm64/ru/all/`.

## Установка и обновления

Универсальный установщик получает опубликованные GitHub Releases, показывает совместимые версии и устанавливает только после явного нажатия. Автоматической установки нет. Приложение отдельно уведомляет об обновлениях Колобка и AI API; подавление стартового окна оставляет постоянное уведомление внутри приложения.

Секреты, API-ключи, Telegram bot token и пользовательские базы запрещено коммитить в репозиторий.

Смотри `docs/RELEASE_LAYOUT.md`, `docs/ROADMAP.md` и `docs/SOURCES.md`.
