# Vercel setup for LabokUS

A new empty Vercel project named kolobok-labokus-web has been created in the selected team. The Vercel API could not link the GitHub repository because the Vercel account has not yet added a GitHub Login Connection.

To finish linking:
1. Open https://vercel.com/dashboard and select the team.
2. Open Account/Team Settings → Integrations or Login Connections → connect the GitHub account that owns Yor​​nerBETA/LabokUS.
3. Open the existing project kolobok-labokus-web.
4. Open Settings → Git → Connect Git Repository.
5. Select Yor​​nerBETA/LabokUS.
6. Set Root Directory to web.
7. Keep Framework as Other/None; this is a static HTML/CSS site.
8. Deploy.

The project currently has no deployment and no domain. Do not add API secrets to the static web directory. The authenticated browser application and API remain hosted separately on Render.
