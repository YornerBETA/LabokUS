# Создание GitLab-проекта LabokUS-Knowledge

У подключённого GitLab-инструментария нет действия создания нового проекта. Поэтому проект автоматически не создан.

1. Открой https://gitlab.com/projects/new
2. Выбери **Create blank project**.
3. Project name: `LabokUS-Knowledge`
4. Project slug: `labokus-knowledge`
5. Visibility: **Private**.
6. Включи Initialize repository with a README.
7. Нажми Create project.
8. Скопируй URL проекта и пришли его — после этого можно добавлять структуру знаний и синхронизацию.

Не делай репозиторий публичным: в нём потенциально будут персональные знания и метаданные. Не загружай API-ключи, пароли, токены Telegram и сырые приватные переписки без отдельного решения о хранении.
